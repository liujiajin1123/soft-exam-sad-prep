# 软考高级系统架构设计师备考资料库

用于持续收集、核验、整理系统架构设计师考试资料，尤其是论文真题、范文、写作框架和评分参考，供考生及后续 Agent 检索、整理与评估。

## 目录约定

- `research/papers/`：论文备考研究报告、题目分析、写作框架与练习材料。
- `research/papers/sources.md`：来源台账。每项注明来源类型、可验证内容、可信度/限制、最后核验日期。
- `research/papers/agent-review-rubric.md`：后续 Agent 对资料进行整理、评价和打分的规范。
- `sources/`：只存放确认允许再分发的自制或开放授权材料；外部网页、付费课程、教材、范文集及不明版权文件默认只登记链接和摘要，不复制原件。

## 资料处理原则

1. **官方事实优先**：考试大纲、考试形式、考试规则以中国计算机技术职业资格网及相关主管部门的现行公开信息为准。官方未公开的内容不得写成官方规则。
2. **来源可追溯**：记录标题、URL、来源/作者、资料类型、适用版本或年份、核验日期以及不确定性。尽量引用原始发布页，而不是二手转载。
3. **版本明确**：旧版范文、历年真题和新版大纲分开标记年份/版本；不把旧资料静默更新成“最新”。
4. **版权谨慎**：不得因文件出现在公开 GitHub 仓库就推定其所有内容可再分发。对第三方资料只记录链接、必要的短摘要和授权状态；若授权不清，不提交文件本体。
5. **评价依据透明**：评分必须说明维度、证据、分数依据和不确定性。官方未发布论文细则时，评分应明确标注为“备考参考量表”，不得冒称官方标准。
6. **保留原始材料与结论的区别**：Agent 的摘要、评分、改写模板单独存放，不覆盖来源文件；对范文的评语应定位到段落/论点并给出理由。
