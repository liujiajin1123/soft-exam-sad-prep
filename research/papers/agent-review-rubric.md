# Agent 资料审核与论文评分规范

## A. 资料质量审核

收到一个资料链接或文件时，先建立资料卡，不要先做无出处的摘要或打分。

```yaml
id: Sxx
title: "资料标题"
source_url: "原始来源URL"
source_author_or_org: "作者/机构；未知则标未知"
source_type: "official | exam_question | sample_essay | tutorial | template | discussion"
publication_or_exam_year: "年份或未知"
retrieved_at: "YYYY-MM-DD"
applicable_syllabus: "大纲版本/待核验"
license_or_reuse_status: "许可名称/不明/不可复制"
verified_claims:
  - "可从原文确认的事实"
limitations:
  - "时效、偏差、缺页、非官方或版权限制"
```

**质量等级（0—4）**

- **4：优先推荐**。来源可验证、版本清楚、完整且与现行大纲匹配；关键事实有官方或可靠原始依据；授权状态清楚。
- **3：推荐但需注明限制**。内容有用且来源基本可追溯，但存在有限的年份/范围/非官方解释等限制。
- **2：仅作线索**。结构或讲解可参考，但出处不完整、时效未知、结论未经充分核验，或有明显商业/个人经验偏向。
- **1：不建议作为备考依据**。关键事实无依据、明显过时/错误、标题夸大，或无法确认资料完整性。
- **0：排除**。来源失效且无法核实、内容与考试无关、存在严重误导，或仓库不应留存该文件（如明显未经许可复制的受版权保护文件）。

每个等级都要写出具体理由。分值不是“权威性”的替代品；官方页面与社区经验不能只靠平均分混为一类。

## B. 论文练习稿评分（100分训练量表）

> 这是仓库自建的练习量表，不是官方评分标准，也不对真实阅卷分数作预测。若日后发现官方公开评分文件，应另列文件来源与生效版本，再经人工确认后修订。

1. **切题与任务覆盖：30分**。逐条映射题目要求；标题和摘要明确主题；正文完整回答题目中的子问。偏题、漏答或用模板套题应扣在本项并说明位置。
2. **架构决策与技术深度：25分**。说明需求/质量属性、约束、备选方案、取舍、关键设计及影响；技术术语准确，论点有因果关系。
3. **项目实践与可信度：20分**。角色和职责明确；项目场景具体且前后一致；规模、时间、指标合理；不夸大，不虚构无法支撑的个人经历。
4. **验证、结果与复盘：15分**。用指标、测试、评审、上线反馈或故障变化验证效果；交代代价、风险、局限和改进。
5. **结构与表达：10分**。摘要、正文和结论相互一致；层次清楚、逻辑连贯、段落可读；缩写、数据和图表表达准确。

### 等级解释

- **90—100：优秀训练稿**。切题完整，决策分析有深度，实践细节可验证，表达成熟；只需小修。
- **75—89：较强训练稿**。主线成立，但个别论点、证据或复盘偏弱；指出最重要的两三处增补方向。
- **60—74：基本成稿**。结构可理解但有明显缺项，常见问题是泛谈技术、项目证据不足或权衡不清；应优先重写薄弱段落。
- **45—59：需大幅修改**。任务覆盖、实践性或论证链存在严重缺口；给出重写提纲，不用润色掩盖结构问题。
- **0—44：不合格练习稿**。偏题、关键要求漏答、内容空泛或事实自相矛盾；先回到题目拆解和项目事实库。

**严重缺陷标记**（另行列示，不重复扣分后又重复扣）：偏题/漏答、项目真实性存疑、未经说明的夸大数据、技术事实错误、关键信息冲突、模板痕迹重、来源/版权不明。

## C. Agent 输出格式

每次审核给出以下字段：

```text
资料ID / 稿件版本：
任务：资料质量审核 / 论文练习评分 / 摘要 / 题目拆解
总分与等级（仅练习稿）：
评分说明：每一维度得分、对应原文证据及理由
主要优点：最多3项
首要问题：按影响从高到低，定位章节/段落
建议修改：可执行、与题目对应的修改动作
官方事实核查：支持链接；未核实项明确标注
时效/大纲匹配：版本、年份及待确认处
版权与转载风险：状态和处理建议
信心：高/中/低及原因
```

论文批阅时先引用题目并拆解要求，再给分。不得仅用“像不像范文”“感觉高分”评分。对于题目与练习稿不匹配、项目材料不足、题目版本未知等情况，先说明评分局限，必要时只给定性意见而不打总分。
